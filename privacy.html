Privacy Policy

Last updated: November 10, 2026

Claudette is a personal tool used only by its owner. It is not offered to the public or to any other users.

What data it accesses

With the owner's permission, Claudette reads events in the owner's Google Calendar and creates or updates events there. It does not delete events.

How the data is used

Calendar data is used only to carry out the owner's own requests, such as adding a reminder or checking the schedule. The relevant text is processed by the AI model the owner uses to run the assistant.

Storage

The Google access token is stored only on the owner's own computer. Calendar data is not stored on any external server operated for this tool.

Sharing

Data is not sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
